# pi-openai-limits

A global Pi package for displaying OpenAI usage limits and resuming paused agents after a limit reset.

## Development

```sh
npm install
npm run lint
npm test
```

During development, load the package directly:

```sh
pi -e /absolute/path/to/pi-openai-limits
```

A hosted Git repository can later be installed globally with `pi install git:<repository>`.
